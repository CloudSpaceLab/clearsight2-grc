# Framework workflow prototype

Derived from the sibling framework-library.html and framework-adoption.html references. Open framework-library.html, choose ISO/IEC 27001:2022 and select Review adoption. The adoption example is limited to that edition because its sample mappings are ISO-specific. Use Library or the breadcrumb to return.

All records and actions are illustrative and exist only in the page; they do not call a backend, save drafts, create proposals or approve changes. Reload resets interactions. Other edition adoption and regulator/add actions show a preview notice. This is a separate design artifact; the main app is unchanged. The reference Home navigation is retained.
