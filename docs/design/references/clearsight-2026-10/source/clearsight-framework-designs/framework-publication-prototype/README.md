# Framework edition publication prototype

Open `index.html` from a local web server and choose **Add framework**. The separate prototype derives its library shell from the adjacent `framework-library.html` reference and complements `framework-adoption.html`. The archived references remain unchanged.

Use the fictional prefilled example to enter edition details, source and rights, add references, review the summary, submit, and simulate an independent reviewer returning or approving it. A simulated approval is shown in a notice in the prototype library. Reset example restores the starting sample.

This is a design simulation. It saves a single example in the browser's local storage, scoped to the browser and origin; changing `localhost`, `127.0.0.1`, or the port changes the storage location. It does not upload documents, authenticate reviewers, verify permissions or rights, call a backend, create an edition in ClearSight, or make an edition available for real adoption. Example names and source are fictional.

The original reference navigation is illustrative. Only the Frameworks library and publication flow are linked in this prototype; this does not alter the main app's navigation.
